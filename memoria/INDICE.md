## CÓMO FUNCIONA

1. **Aprendo algo** → Creo un archivo en `memoria/` con el conocimiento
2. **Lo indexo aquí** → Agrego una entrada a este índice
3. **Lo consulto** → Antes de responder, reviso si hay algo relevante
4. **Te muestro** → Siempre te digo: "Según lo que aprendí en [tema]..."

## ESTRUCTURA COMPLETA DE MEMORIA

```

├── INDICE.md                  ← Este archivo (índice general)
├── 001-*.md                   ← Lecciones aprendidas
├── 002-*.md
├── ...
└── pendientes/

    ├── 001-*.md               ← Cada pendiente es un caso documentado
    └── ...
```
